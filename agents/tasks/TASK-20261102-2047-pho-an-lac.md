# Phố An Lạc — Xích Lô Đêm / Xe Ôm Vòng Phố

## Wish being fulfilled
Players want the **street to move** — not only stand at shop doors. Soft IRL fantasy: hop a xích lô (or xe ôm) and glide the length of Phố An Lạc past cà phê / phở / tóc / trà đá, wind in the face, like a tiny movie only this game can give outside the gate.

## Player fantasy loop (addictive)
1. **Discover** — after `goToStreetGate` / FAB / KeyP (~x 20.2), spot a glowing **bến xích lô** mid-street (near existing decorative bikes or a new stand). Proximity tip: **「Lên xích lô」** within ~30s of arriving on phố  
2. **Interact** — press interact → short auto-ride (~6–10s) along the asphalt (+X/−X loop or out-and-back). Camera slight chase / over-shoulder; player locked as passenger; shops fly by  
3. **Reward** — first ride: toast Vietnamese + công đức + Sổ line **🛤️ Xích lô Phố An Lạc**; light VFX (dust trail / wheel spin / soft headlight); optional tiny “ting”  
4. **Escalate** — ride count → unlocks: (a) **chuyến 2** faster “xe ôm gấp”, (b) after 3 rides **chuyến đêm đèn lồng** (street lamps pulse / warm glow regardless of global weather), (c) flair **Hành Khách Xích Lô** when 3+ rides; soft daily tip “đi một vòng phố” if streak tips already exist (do not hard-rewrite streak)  
5. **Show off** — flair on merit chip / `templeFlairSuffix`; Sổ section lists chuyến đã đi; friends see a street rider, not only Khách Phố shopper
