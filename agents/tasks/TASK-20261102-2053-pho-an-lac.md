# Phố An Lạc — Karaoke Loa Kéo Vỉa Hè

## Wish being fulfilled
Players want the street to **sing** — not only shops and rides. Soft IRL fantasy: a **loa kéo** (street karaoke speaker) spills a chorus onto Phố An Lạc; you grab the mic for one beat, the sidewalk lights pulse, and the whole phố feels like a tiny wedding-band night that only this game can stage outside the gate.

## Player fantasy loop (addictive)
1. **Discover** — after street warp (FAB / KeyP / ~x 20.2), hear/see a glowing **loa kéo** stand on the vỉa hè (mid-street curb, e.g. near x≈20–21, z≈STREET_Z+4.6 or sidewalk not overlapping shop doors / gossip ring / bến xích lô). Proximity tip within ~30s: **「Hát karaoke」**
2. **Interact** — press interact → short **hát 1 đoạn** (~5–8s): player locked facing loa, mic prop or arm raise, lyrics/toast lines in Vietnamese scroll or toast; sidewalk ring pulse + soft speaker bob; optional nearby shop tip emissive bump. Esc / Hủy = snap end (still counts as attempt if ≥1.5s)
3. **Reward** — first song: toast VN + công đức + Sổ line **🎤 Karaoke Phố An Lạc**; light VFX (note sparks / ring pulse). Soft “ting” / reuse whoosh if easy
4. **Escalate** — song count → unlocks: (a) **bài 2** “Remix đám cưới” (faster pulse + warmer sidewalk glow), (b) after 3 songs **đêm loa vàng** (street lamps near loa pulse gold in sync — reuse `S.streetLamps`, do not break xích lô đêm), (c) flair **Ca Sĩ Vỉa Hè** at 3+; soft daily tip “hát một bài trên phố” if streak tips exist (do not hard-rewrite streak)
5. **Show off** — flair on merit chip / `templeFlairSuffix`; Sổ section lists bài đã hát; friends see a street singer, not only Khách Phố / Hành Khách Xích Lô
