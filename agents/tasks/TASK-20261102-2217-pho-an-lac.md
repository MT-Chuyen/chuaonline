# Phố An Lạc — Bóng Đá Vỉa Hè · Khung Thành Bay

## Wish being fulfilled
Players want the classic VN street fantasy that is IRL-impossible on a temple gate street: a **khung thành bóng đá bay lơ lửng trên hè**, mình **chạm bóng / sút phạt / volley**, bàn thắng nổ sao — phố vỗ tay như khán đài mini. Soft duyên with the temple’s Ronaldo–Messi poster (do **not** rewrite pagoda art): street football identity, not idol romance.

## Player fantasy loop (addictive)
1. **Discover** — after street warp (FAB / KeyP / bridge ~x 15.2), soft tip within ~30s: **「Khung thành đang bay cuối hè…」**. Visual: floating goal posts + ball mesh + tip plane **⚽ Khung Thành Bay** at **east-north curb** past bến xích lô / near hair east pocket — **clear of** Boy Phố west, Giờ Vàng mid-lane annulus, karaoke, shops doors, hốt họ, mưa trà, Phóng Lợn alley spine, Kỳ Ảo hooks, music screen.
2. **Interact** — stand near goal → Vietnamese verbs cycle by progress: **Chạm bóng** → **Sút phạt** → **Volley bay**. Each uses `S.busy` (~6–14s). Esc/Hủy after ≥1.2s still counts 1 lượt nhẹ (toast + tiny công đức if already touched ball).
3. **Reward** — first chạm: toast VN + công đức + Sổ line **⚽ Bóng Đá Vỉa Hè · chạm bóng**; first bàn (sút/volley finish): bigger merit + star burst / crowd cheer whoosh. Soft tip “phố nhớ cú sút” after 1 bàn.
4. **Escalate** — persist counts unlock ≥3 bậc: (a) after 1 chạm → unlock **Sút phạt**, (b) after 1 bàn hoặc 2 chạm → unlock **Volley bay** + flair **Cầu Thủ Phố**, (c) after 3 bàn (sút+volley finishes) → flair **Siêu Sao Hè** + taller floating goal / denser star trail. Soft duyên: if player has visited courtyard Ronaldo–Messi poster area this session OR `khachPho` / ≥1 shop visit, tip / +1 công đức on next bàn (do not rewrite poster mesh or shops).
5. **Show off** — flair **Cầu Thủ Phố** / **Siêu Sao Hè** on merit chip / `templeFlairSuffix`; Sổ lists lần chạm / bàn / volley; friends see street-football guest — not Khách Phố / Ca Sĩ Vỉa Hè / Hành Khách Xích Lô / Chủ Họ / Bạn Trà Mưa / Khách Giờ Vàng / Bạn Phố / Anh Em Phố sequels.
