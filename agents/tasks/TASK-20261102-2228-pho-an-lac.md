# Phố An Lạc — Phở Bay · Bát Hơi Thăng

## Wish being fulfilled
Players want the classic VN street food fantasy that is IRL-impossible outside a temple gate: **tô phở thật sự bay lên theo hơi nóng**, mình **gọi phở / hít hơi / ăn bát bay** trước **Phở Bà Tư** — khói thành sân khấu mini, phố “nghiện” một tô như clip viral nhưng chỉ có trên Phố An Lạc.

## Player fantasy loop (addictive)
1. **Discover** — after street warp (FAB / KeyP / bridge ~x 15.2), soft tip within ~30s: **「Khói phở đang bay trước Bà Tư…」**. Visual: 1–2 floating bowl meshes + steam wisps + tip plane **🍜 Phở Bay** on **south curb at Phở Bà Tư** — **clear of** hốt họ (~20.5 / STREET_Z−4.75), mưa trà (~23.9 / −5.65), paper-mail Kỳ Ảo (~19.15 / −2.75), tea door, karaoke north, Boy Phố west, Bóng Đá east-north, Giờ Vàng mid-lane.
2. **Interact** — stand near bowls → Vietnamese verbs cycle by progress: **Gọi phở** → **Hít hơi** → **Ăn bát bay**. Each uses `S.busy` (~6–14s). Esc/Hủy after ≥1.2s still counts 1 lượt nhẹ (toast + tiny công đức if already gọi).
3. **Reward** — first gọi: toast VN + công đức + Sổ line **🍜 Phở Bay · gọi tô**; first ăn finish: bigger merit + steam burst / bowl-orbit cheer. Soft tip “Bà Tư nhớ tô của mình” after 1 ăn.
4. **Escalate** — persist counts unlock ≥3 bậc: (a) after 1 gọi → unlock **Hít hơi**, (b) after 1 ăn hoặc 2 gọi → unlock **Ăn bát bay** + flair **Khách Phở Bay**, (c) after 3 ăn (hít-finish optional + ăn finishes; count **Ăn bát bay** finishes primarily, Hít hơi may count ½ or soft tip only — prefer: **3× Ăn bát bay**) → flair **Thực Thần Phố** + taller bowl orbit / denser steam. Soft duyên: if `khachPho` / ≥1 shop visit / already visited `pho` this session, tip / +1 công đức on next ăn (do not rewrite shop menus of cafe/hair/tea).
5. **Show off** — flair **Khách Phở Bay** / **Thực Thần Phố** on merit chip / `templeFlairSuffix`; Sổ lists lần gọi / hít / ăn; friends see street-phở guest — not Khách Phố / Ca Sĩ Vỉa Hè / Hành Khách Xích Lô / Chủ Họ / Bạn Trà Mưa / Khách Giờ Vàng / Bạn Phố / Anh Em Phố / Cầu Thủ Phố sequels.
