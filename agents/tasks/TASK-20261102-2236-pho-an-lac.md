# Phố An Lạc — Cờ Tướng Bay · Quân Phi

## Wish being fulfilled
Players want the classic VN vỉa-hè fantasy that is IRL-impossible: **bàn cờ tướng trên ghế nhựa** nhưng **quân thật sự bay lên đấu**, mình **ngồi bàn / đặt quân / xuống tướng bay** — phố vỗ tay như kỳ thủ sân khấu mini, chỉ có trên Phố An Lạc.

## Player fantasy loop (addictive)
1. **Discover** — after street warp (FAB / KeyP / bridge ~x 15.2), soft tip within ~30s: **「Cờ tướng đang bay trên hè…」**. Visual: low board + 2 ghế nhựa + 3–5 floating piece meshes (tướng/mã/pháo cheap cyl+box) + tip plane **♟️ Cờ Tướng Bay** on **south-mid east curb** — **clear of** paper-mail Kỳ Ảo (~19.15 / STREET_Z−2.75), hốt họ (~20.5 / −4.75), mưa trà (~23.9 / −5.65), rewind lamp (~24.6 / −3.55), Phở Bay (~19.55 / −6.55), karaoke north, Boy Phố west, Bóng Đá east-north, Giờ Vàng mid-lane (may sit inside Giờ Vàng annulus — Giờ Vàng stays lowest).
2. **Interact** — stand near board → Vietnamese verbs cycle by progress: **Ngồi bàn** → **Đặt quân** → **Xuống tướng bay**. Each uses `S.busy` (~6–14s). Esc/Hủy after ≥1.2s still counts 1 lượt nhẹ (toast + tiny công đức if already ngồi).
3. **Reward** — first ngồi: toast VN + công đức + Sổ line **♟️ Cờ Tướng Bay · ngồi bàn**; first xuống tướng finish: bigger merit + piece-clash spark / soft street cheer. Soft tip “bàn nhớ nước của mình” after 1 duel finish.
4. **Escalate** — persist counts unlock ≥3 bậc: (a) after 1 ngồi → unlock **Đặt quân**, (b) after 1 xuống tướng hoặc 2 ngồi → unlock **Xuống tướng bay** + flair **Kỳ Thủ Phố**, (c) after 3× **Xuống tướng bay** finishes → flair **Tướng Phố** + taller piece orbit / denser clash sparks. Soft duyên: if `khachPho` / ≥1 shop visit / visited `cafe` this session, tip / +1 công đức on next xuống tướng (do not rewrite cafe/hair/tea/pho menus).
5. **Show off** — flair **Kỳ Thủ Phố** / **Tướng Phố** on merit chip / `templeFlairSuffix`; Sổ lists lần ngồi / đặt / xuống tướng; friends see street-chess guest — not Khách Phố / Ca Sĩ Vỉa Hè / Hành Khách Xích Lô / Chủ Họ / Bạn Trà Mưa / Khách Giờ Vàng / Bạn Phố / Anh Em Phố / Cầu Thủ Phố / Khách Phở Bay / Thực Thần Phố sequels.
