# Phố An Lạc — Bi Ve Bay · Bắn Bi Hè

## Wish being fulfilled
Players want the classic VN childhood fantasy that is IRL-impossible on a crowded street: **vòng phấn bi ve trên hè**, bi **thật sự bay vòng / lao vào vòng phấn giữa không** — mình **nhặt bi → bắn bi → bi bay vòng**, phố vỗ tay như tay bi sân khấu mini, chỉ có trên Phố An Lạc.

## Player fantasy loop (addictive)
1. **Discover** — after street warp (FAB / KeyP / bridge ~x 15.2), soft tip within ~30s: **「Bi ve đang bay trên hè…」**. Visual: chalk-ring disc on curb + 4–6 small glass-like bi (cheap spheres / low-poly balls, tinted) gently orbiting 0.6–1.6m over the ring + tip plane **🔮 Bi Ve Bay** on **south-west curb** — **clear of** Boy Phố (~14.9 / STREET_Z+2.35), love-light Kỳ Ảo (~16.55 / STREET_Z), paper-mail (~19.15 / −2.75), hốt họ (~20.5 / −4.75), Phở Bay (~19.55 / −6.55), Cờ Tướng (~22.8 / −2.4), karaoke north, Bóng Đá east-north, Giờ Vàng mid-lane (annulus OK — Giờ Vàng stays lowest).
2. **Interact** — stand near ring → Vietnamese verbs cycle by progress: **Nhặt bi** → **Bắn bi** → **Bi bay vòng**. Each uses `S.busy` (~5–14s). Esc/Hủy after ≥1.2s still counts 1 lượt nhẹ (toast + tiny công đức if already nhặt).
3. **Reward** — first nhặt: toast VN + công đức + Sổ line **🔮 Bi Ve Bay · nhặt bi**; first bi-bay-vòng finish: bigger merit + marble-trail sparks / soft street cheer. Soft tip “bi nhớ tay mình” after 1 bay-vòng finish.
4. **Escalate** — persist counts unlock ≥3 bậc: (a) after 1 nhặt → unlock **Bắn bi**, (b) after 1 bi bay vòng hoặc 2 nhặt → unlock **Bi bay vòng** + flair **Tay Bi Phố**, (c) after 3× **Bi bay vòng** finishes → flair **Chúa Bi Hè** + taller orbit / denser spark trails. Soft duyên: if `khachPho` / ≥1 shop visit / visited `tea` this session, tip / +1 công đức on next bi bay vòng (do not rewrite cafe/hair/tea/pho menus).
5. **Show off** — flair **Tay Bi Phố** / **Chúa Bi Hè** on merit chip / `templeFlairSuffix`; Sổ lists lần nhặt / bắn / bi bay vòng; friends see street-marble guest — not Khách Phố / Ca Sĩ Vỉa Hè / Hành Khách Xích Lô / Chủ Họ / Bạn Trà Mưa / Khách Giờ Vàng / Bạn Phố / Anh Em Phố / Cầu Thủ Phố / Khách Phở Bay / Thực Thần Phố / Kỳ Thủ Phố / Tướng Phố sequels.
